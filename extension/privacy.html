Data handling

This independent university project backs up the complete HTML returned by the COMSATS Lahore RESULTCARD page as a private cloud text file. Report-card generation is planned separately and is not a feature of this extension.

Collection is disabled until you explicitly enable it. After consent, the extension observes portal document requests and fetches RESULTCARD using your existing portal session. The whole response may contain student identifiers, grades, academic history, and hidden fields. It does not extract individual grades.

The file is uploaded over HTTPS to the project operator’s Supabase Storage bucket. The operator and people they authorize can access uploaded files. Your portal password and browser cookies are not included in the upload request. The full HTML is transmitted without redacting embedded values.

The extension stores consent, upload status, and a random installation identifier locally. HTML pending upload is kept only in Chrome’s session storage and is removed after success, exhausted retries, or disabling uploads. Closing the browser clears pending HTML.

Each detected login creates a new file. Prior files are retained in cloud storage; disabling or uninstalling does not remove them. No analytics, advertising, or third-party scripts are included.

Project deployment notice: Before distributing this extension, the operator must provide their identity, a working privacy/deletion contact, a retention period, and a hosted privacy policy. This bundled description is not a complete publication policy.
